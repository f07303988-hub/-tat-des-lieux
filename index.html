1. Créer un état des lieux

Depuis l'écran d'accueil, appuyez sur le bouton bleu « + Nouvel état des lieux » en bas de l'écran. Un même dossier contient à la fois l'état d'entrée et l'état de sortie.

2. Passer de l'entrée à la sortie

En haut du formulaire, les boutons « État d'entrée » et « État de sortie » permettent de basculer entre les deux dans le même dossier. La première fois que vous ouvrez « État de sortie », les quantités de matériel prévues et les informations de clés sont automatiquement reprises de l'entrée, sans tout ressaisir.

3. Remplir les sections

Chaque section (Informations générales, pièces...) s'ouvre en appuyant dessus. Pour chaque élément, appuyez sur Bon, Moyen ou Mauvais. Un champ d'observation apparaît automatiquement si vous choisissez Moyen ou Mauvais. Le compteur sous les boutons Entrée/Sortie indique combien de sections sont complètes.

4. Ajouter des photos

Dans chaque pièce, appuyez sur « + Photo » pour prendre une photo d'une dégradation. La date et l'heure sont enregistrées automatiquement avec chaque photo. Appuyez sur ✕ pour supprimer une photo.

5. Signaler une fenêtre abîmée

Pour les pièces suivies (grande salle, petite salle...), choisissez le numéro de la fenêtre ou porte-fenêtre concernée dans le menu déroulant puis appuyez sur « + Signaler ». Les fenêtres non signalées sont considérées en bon état.

6. Mobilier et matériel

Indiquez la quantité prévue et la quantité constatée pour chaque objet (tables, chaises, vaisselle...). Un écart s'affiche automatiquement s'il manque des éléments.

7. Signatures

Faites signer avec le doigt directement sur l'écran, pour la commune et pour le locataire. Appuyez sur « Effacer la signature » pour recommencer.

8. Terminer un état des lieux

Appuyez sur Terminer pour enregistrer. Exporter / imprimer ouvre un aperçu dans l'appli avec un bouton « ✕ Fermer » pour revenir, et un bouton « Imprimer / PDF ». Partager ouvre le menu de partage de l'appareil (Mail, Messages, AirDrop, Fichiers, WhatsApp...) avec le document complet et un résumé.

9. Retrouver un état des lieux

Sur l'écran d'accueil, utilisez la barre de recherche (par nom, objet, numéro EDL ou date) ou les filtres (Tous / Entrée à faire / Sortie à faire / Avec points signalés) pour retrouver un dossier. Appuyez sur une fiche pour la rouvrir, ou sur ✕ pour la supprimer.

10. Gérer plusieurs salles

Le bouton 🏛 en haut de l'écran d'accueil ouvre « Mes salles ». Chaque salle a ses propres pièces suivies, son propre matériel et son propre historique, entièrement indépendants. Utilisez « + Ajouter une salle » pour en créer une nouvelle (activée automatiquement), et le bouton − pour en supprimer une (au moins une salle doit toujours rester). Dès que vous avez 2 salles ou plus, un menu déroulant apparaît en haut de l'écran d'accueil pour basculer rapidement de l'une à l'autre.

11. Code d'accès et sécurité

Le code à 6 chiffres demandé à l'ouverture n'est pas qu'un simple verrou : vos données (noms, téléphones, photos, signatures) sont réellement chiffrées avec. Sans ce code, personne ne peut les lire — y compris vous. Dans Configuration, générez un code de récupération (24 caractères, imprimable) et conservez-le ailleurs que sur ce téléphone : c'est le seul moyen de tout récupérer si le code du quotidien est oublié. Sur l'écran de verrouillage, le lien « Code oublié ? » permet de l'utiliser. Vous pouvez aussi régler un verrouillage automatique après quelques minutes d'inactivité (Configuration) : un bandeau vous prévient juste avant qu'il ne se déclenche ; Face ID/empreinte suffit ensuite à rouvrir l'écran verrouillé. Le code redevient obligatoire uniquement après une fermeture complète de l'application.

12. Sauvegarder vos données

Un message en haut de l'écran d'accueil indique depuis combien de temps vous n'avez pas sauvegardé (il passe en rouge après 14 jours, et une alerte s'affiche s'il n'y a jamais eu de sauvegarde ou que ça date de plus d'un mois). Appuyez directement sur ce message, ou sur « Sauvegarder toutes les données » plus bas, pour télécharger un fichier de secours (toutes les salles y compris) — 🔒 les sauvegardes sont désormais chiffrées, sans code supplémentaire à retenir : elles utilisent votre code utilisateur du moment. Une ancienne sauvegarde reste liée au code qui était actif quand elle a été créée, même si vous en changez ensuite. En cas de problème sur le téléphone, utilisez « Restaurer une sauvegarde » et indiquez le code correspondant à ce fichier pour tout récupérer.
